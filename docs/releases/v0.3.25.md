# Arco v0.3.25

邀请 Arco 通过本机音频参与线上、线下和混合会议。

- 「语音提问」升级为「邀请 Arco 入会」：邀请后打开独立悬浮窗，使用 LiveKit Agents UI Aura 着色器的原生 Metal 移植，动效随聆听、思考和说话状态变化。
- 明确区分收起与离会：收起只隐藏窗口，再次点击「Arco 已入会」找回；离会自动关窗、结束语音并恢复麦克风，会议转写继续。只有标题区域可拖动，动效区域不拖动。
- 混合模式同时听取系统音频与现场麦克风；每轮点名 Arco / 阿可后才回应，减少旁听时插话。
- 可选会议音频配置提前到首次引导，允许跳过并在设置补齐。应用内获取官方 BlackHole 2ch 安装器，配有真实飞书截图指引。
- 飞书麦克风选择一次「与系统一致」后，Arco 入会时切换系统输入，离会时恢复；会议发送线路混合现场麦克风与 Arco 回复，避免回送远端系统声。
- 修复失效的已保存麦克风导致录音启动失败，以及蓝牙麦克风采样率变化导致的录音进程崩溃。
- 统一邀请入口与状态的对齐，更新中英文 README 和真实产品截图。

GPT Live 仍为主动开启的 Beta，需要连接 ChatGPT。Arco 通过本机音频参与，不作为飞书成员出现在参会名单。BlackHole 安装需要 macOS 管理员授权；会议应用固定选择某个麦克风时，不会自动跟随系统切换。

验证覆盖原生界面交互、真实模型连接、物理麦克风采集、虚拟设备混音与路由恢复。真实远端听感、长时间漂移与多人重叠讲话仍有待进一步实地验收。

安装包：Apple Silicon，macOS 14 或更新版本，附 SHA-256 校验文件。使用稳定的本地开发签名，尚未经过 Apple 公证。Aura 着色器保留上游第三方许可声明。

连续对话暂未进入此版本：实验门控已实现，但真实模型测试出现称呼识别错误和背景误接话，尚未通过验收。
