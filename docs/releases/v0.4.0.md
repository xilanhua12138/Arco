# Arco 0.4.0

## Microphone recovery

- Recover when a microphone disconnects or stops delivering audio frames; prefer an available physical microphone over virtual loopback devices.
- Restore the preferred device when it returns, with bounded retry delays for stalled devices.
- Rebuild microphone capture when the Bluetooth audio format changes while preserving the system-audio stream.
- Treat valid silent audio as silence and add separate microphone quality metrics before and after echo cancellation.

## Settings stability

- Query audio device availability directly through Core Audio when opening Settings, avoiding nested layout caused by waiting for a helper process on the main thread.

## Validation

Recorder recovery self-tests and 16 Rust audio-runtime tests passed. A 12-second built-in microphone check received non-silent PCM. 367 native UI assertions passed. The installed 0.4.0 app passed repeated accessibility-driven Settings open/close checks. Physical AirPods unplug/reconnect testing remains pending.
