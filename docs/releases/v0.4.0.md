# Arco v0.4.0

## 会议记录管理

- 在历史会议记录上右键归档或删除。
- 在设置的「数据与隐私」中查看归档会议并恢复到历史列表。
- 删除前确认会议名称，将会议记录、关联录音及附属数据移入系统废纸篓。

## 菜单与设置

- 右键菜单与设置中的「更多」菜单使用不透明浅色背景、左侧线条图标和圆角蓝色高亮。
- 加宽设置下拉菜单与左右留白，长选项支持换行。
- 支持方向键选择、回车执行、Esc 关闭和点击外部关闭。
- 打开设置时直接通过 Core Audio 查询设备，修复同步等待辅助进程引起的界面重入问题。

## 麦克风恢复

- 麦克风断开或停止传入音频帧时重连，自动选择时优先使用可用的实体麦克风。
- 首选设备恢复后重新连接，限制异常设备的重试频率。
- 蓝牙音频格式变化时重建麦克风采集，保留系统音频流。
- 区分正常静音与采集停滞，增加回声消除前后的音量诊断。

## 安装与验证

适用于 Apple Silicon Mac，要求 macOS 14 或更新版本。下载 `Arco-macos-arm64.dmg`，打开后将 Arco 拖入「应用程序」。此预览版使用本地开发签名，尚未经过 Apple 公证。

录音器自测、16 项音频运行时测试、会议管理集成测试、菜单渲染与键盘交互测试、设置控件测试和 21 项历史页面性能检查通过。本机麦克风短时检查收到有效语音信号，安装包签名与 SHA-256 校验通过。

实体蓝牙设备断开与重连验证仍待完成；最后一轮实机菜单点检受系统截图工具异常影响，菜单外观与交互已通过 AppKit 渲染和事件回归检查。
