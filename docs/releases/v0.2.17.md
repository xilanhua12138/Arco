# Arco 0.2.17

Arco 0.2.17 keeps meeting titles aligned with the conversation as it develops and closes the recording HUD as soon as capture stops.

## Improvements

- Regenerates the active meeting title once per five-minute recording window, even when History, Notes, or another meeting is currently selected.
- Regenerates the title once more from the completed transcript when recording stops, before producing the end-of-meeting summary.
- Uses the complete current transcript for generated meeting output and explicitly derives each result afresh instead of preserving an earlier partial title.

## Fixes

- Replaces generated title artifacts safely while preserving one-shot behavior for summaries.
- Prevents automatic generation from overwriting a title that the user edited, including a deliberate untitled state and a rename that races an in-flight generation.
- Releases the HUD immediately when capture leaves the recording phase instead of waiting for backend shutdown work.
- Treats title-generation claims as in-flight coordination rather than permanent locks, so later five-minute and final refreshes can run.

## Validation

- Covers five-minute boundaries, fractional capture timestamps, page changes during recording, duplicate-window suppression, final title ordering, and immediate HUD release in Swift contracts.
- Covers long full-transcript regeneration, artifact replacement, and manual-title protection in Rust integration tests.
- Passes the complete native UI, Rust, recorder, and local-transcription test suite, strict Clippy, and the real Arco app build.
