# Arco 0.2.18

Arco 0.2.18 makes the first start of a listening session visible and reliable, and closes the native runtime cleanly without treating the main-window close button as an application quit.

## Fixes

- Shows the recording HUD immediately on the first click while the provider and capture backend start, instead of leaving the interface apparently unresponsive.
- Clears stale HUD completion state before a new capture and releases the HUD when startup fails.
- Prevents repeated HUD presentation from restarting its lifecycle while a capture is already active.
- Keeps Arco running when the main window is closed, matching normal macOS application behavior.
- Shuts down the Rust backend explicitly during application termination and waits for active FFI calls before destroying the runtime.
- Finalizes an interrupted active transcript during application shutdown instead of leaving it marked as live.

## Validation

- Covers first-click HUD preparation, startup-failure cleanup, repeated HUD presentation, close-window behavior, and explicit backend shutdown in Swift contract tests.
- Covers active-capture shutdown and transcript finalization in Rust integration tests.
- Passes native UI, overlay parity, window chrome, Doubao, active-capture, release build, code-signing, and native-boundary verification.
