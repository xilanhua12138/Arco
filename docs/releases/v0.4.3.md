# Arco 0.4.3

新保存的转录把句级和词级时间写入同名 `.md.timing.json` 元数据文件，Markdown 保留转录正文。应用继续支持读取历史文件里的时间注释。

- 构建应用时重新编译 Deepgram、ElevenLabs、豆包和本地转写组件，防止安装包带入仍向 Markdown 写时间注释的旧组件。
- 修复本地转写把多条发言的元数据序号写成 0 的问题。连续发言和续录分别保存对应时间，播放定位使用正确的记录。
- 更新中文界面文案，增加“开机自启”设置。开关读取 macOS 的注册状态，用户开启后才注册登录项。

发布验证包括转写与会议解析测试、本地转写连续写入和续录测试、实际语音转写的文件检查，以及安装包签名、资源加载和 DMG 校验。
