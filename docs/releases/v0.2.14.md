# Arco 0.2.14

Arco 0.2.14 completes the native desktop migration: SwiftUI now owns every app surface, while Rust owns the backend, capture orchestration, cloud transcription, and the real-time audio runtime.

## Highlights

- Removes the Tauri/WebView runtime and preserves the existing React product flow in native SwiftUI, including Current, History, Notes, Settings, the recording HUD, and Ask Arco.
- Restores source-accurate window chrome, title-bar geometry, button hit targets, navigation state, editable titles, and compact Agent/transcript controls.
- Keeps Liquid Glass on the user-facing HUD and Agent windows while using an opaque main window to avoid continuously compositing the full desktop behind Arco.
- Moves callback-sensitive buffering and sample-rate conversion into a statically linked Rust audio runtime built on `rtrb` and `rubato`.
- Repairs Doubao streaming ASR framing, initialization, reconnect replay, speaker ordering, and EOF finalization so the existing single API Key setup produces and safely saves transcripts.

## Reliability and performance

- Reuses fixed-capacity real-time audio storage and keeps allocation, file IO, and model work off Core Audio callbacks.
- Flushes the final resampler and stereo FIFO tail to transcription before recorder shutdown, so the last word is not truncated.
- Cleans up recorders, provider sidecars, process groups, taps, streams, and Rust audio handles in deterministic order.
- Keeps history loading and live transcript observation from invalidating the static full-window artwork.
- Surfaces failed Notes, History, HUD, and Agent actions instead of leaving controls that appear unresponsive.
- Keeps capture and model workers process-isolated; static archives, C headers, dynamic audio-runtime libraries, and build caches stay outside the shipped payload.

## Validation

- Rust unit and integration tests for the backend and audio runtime, Rustfmt, and Clippy with warnings denied.
- SwiftUI source-parity, window-chrome, settings, history-performance, preferences, localization, and overlay interaction contracts.
- Native recorder and local-transcriber self-tests, signed-app boundary checks, mounted-DMG verification, and a real Doubao single-Key Chinese audio end-to-end run.
