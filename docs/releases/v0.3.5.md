# Arco 0.3.5

Arco 0.3.5 brings Deepgram streaming onto the same bounded, live-edge-first recovery model used by the LiveKit reference implementation.

## Fixes

- Enables Deepgram interim results so the current hypothesis reaches the main window and HUD immediately, while only finalized segments are committed to the meeting Markdown.
- Clears tentative Deepgram text when a final segment commits or the socket disconnects, preventing a stale line from remaining pinned in place.
- Drains only unsent recorder audio into a replacement WebSocket at socket-backpressure speed. A failed send no longer restores the attempted frame or replays the backlog against an application audio clock.
- Limits Deepgram to three consecutive recovery attempts. Only a non-empty final transcript resets the retry budget and backoff; opening a connection, keepalives, metadata, and interim text do not hide a stalled provider.

## Validation

- Adds red-first tests for interim/final separation, live-sidecar cleanup, reconnect catch-up speed, sent-versus-unsent ownership, and bounded retry reset semantics.
- Passes the Rust core and backend integration suites, SwiftUI/source-parity contracts, recorder self-test, local transcription self-test, formatting, and Clippy with warnings denied.
