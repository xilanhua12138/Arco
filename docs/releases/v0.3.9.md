# Arco 0.3.9

Arco 0.3.9 shows the actual transcript path in the meeting-details card.

## Features

- The storage row now displays the tilde-abbreviated transcript path (`~/Library/Application Support/Arco/transcripts/transcript-….md`) instead of the generic "on this Mac" label. The copy button still writes the full absolute path to the pasteboard, and the full path is exposed to accessibility.

## Validation

- TopBar contract test asserts the row renders the tilde-abbreviated path; all affected Swift contract suites pass.
