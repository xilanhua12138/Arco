# Arco v0.3.29

减少历史记录滚动与录音回放时的界面计算开销。

- 转录行独立更新，播放进度不再每 80 毫秒触发整个转录容器刷新。
- 字词播放链接只在文本或录音可用状态改变时重建；高亮只在当前字词变化时更新。
- 用时间索引查找当前句子，保持重叠发言、空档和句尾边界的定位行为。
- 历史记录停止计算实时转录专用的滚动底部位置，手动滚动暂停跟随时避免重复写入状态。

验证包括一万行转录的索引与原顺序查找结果对比、观察状态更新次数、字词链接缓存，以及原生 UI、历史页、Markdown 和真实音频播放测试。以上验证覆盖计算开销与功能正确性；本次未取得滚动帧率实测数据。

适用于 Apple Silicon、macOS 14 或更新版本。附 SHA-256 校验文件；使用稳定本地开发签名，尚未经过 Apple 公证。
