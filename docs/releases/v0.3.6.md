# Arco 0.3.6

Arco 0.3.6 stops the Doubao reconnect storms that inflated one voice into dozens of speaker labels during long meetings.

## Fixes

- Keeps speaker labels stable across WebSocket reconnects. Doubao restarts speaker numbering from 1 on every session, so keying Arco labels by (connection, provider slot) minted a new "speaker" per reconnect — a 51-minute two-person meeting showed 30 labels.
- Widens the live-response watchdog from 12s to 60s. The optimized endpoint only sends packets when results change, so a busy two-pass backlog looked like a dead connection and retriggered the very reconnect that created it.
- Caps reconnect backoff at 5s instead of 15s. Backoff time is pure backlog growth while audio keeps arriving.

## Validation

- Updates the speaker-registry and backoff tests to assert cross-reconnect label reuse and the tighter cap.
- Passes all Rust core and backend integration tests.
