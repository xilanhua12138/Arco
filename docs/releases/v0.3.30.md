# Arco v0.3.30

历史会议列表和历史转录稿改用系统原生列表，减少滚动时的行创建与布局开销。恢复转录行的悬停反馈，保留现有播放器、文字选择、字词跳转和播放跟随。

- 用 SwiftUI `List` 替代这两个页面的 `ScrollView + LazyVStack`，由 macOS 的表格视图管理行复用。
- 使用稳定的会议、转录行标识，并设置合理的行高，避免首屏提前创建大量行。
- 历史会议继续按日期分组，保留搜索、会议预览和选中状态。

原生视图验证：分别载入一万条会议、一万条转录，首屏只创建 10 和 11 个 `NSTableRowView`，数据条数完整。原生 UI、内容布局和录音播放联动测试通过。实际滚动帧率仍需设备复测；测试环境中的 SwiftUI 列表初始化会输出 NSTableView 重入警告，未出现崩溃或行数据缺失。

参考：[Apple 的列表性能说明](https://developer.apple.com/videos/play/wwdc2023/10160/)、[NSTableView 视图复用机制](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/TableView/TableViewOverview/TableViewOverview.html)。

适用于 Apple Silicon、macOS 14 或更新版本。附 SHA-256 校验文件；使用稳定本地开发签名，尚未经过 Apple 公证。
