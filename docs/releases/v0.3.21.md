# Arco 0.3.21

## 更简洁的设置

- 统一通用、聆听与记录、与 Arco 对话、数据与隐私四个分类及其详情页。
- 删除重复说明与多余卡片，常用设置采用左侧名称、右侧操作的布局。
- 录音存储集中展示开关、已用容量、容量上限和打开文件夹；位置管理、格式与隐私说明按需展开。
- 识别服务和说话人分离改为直接选择，只有选择本地识别时才展示模型配置。
- 文字对话保留主要服务、备用服务和连接测试，安装详情可展开；更换服务后仍须重新测试才能保存。
- 保留录音期间的设置锁定、错误提示，以及存满自动清理旧录音、保留文字记录的规则。

## 字标

- Arco 字标改用随应用附带的 Syne Bold；正文和其他界面文字继续使用系统字体。

## 安装

下载 `Arco-macos-arm64.dmg`，打开后将 Arco 拖入 Applications 替换旧版本。已有会议记录和设置会保留。
