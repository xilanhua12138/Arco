# Arco v0.3.23

- 重新整理设置页：统一布局、下拉选择、操作按钮和焦点样式。
- 文字对话的主要／备用服务选择后自动保存；提示词编辑和密钥验证仍保留明确的保存操作。
- 凭证改为存储在本机 `~/.arco/credentials.json`，应用不再读写钥匙串。目录权限为 `700`，文件权限为 `600`；更新某个服务不会覆盖其他服务的凭证。
- 移除侧栏聆听按钮的液态玻璃效果，统一为纯色按钮。

升级说明：旧版本保存在钥匙串中的凭证需要在设置里重新填写，或按照[迁移说明](https://github.com/xilanhua12138/Arco/blob/v0.3.23/docs/features/credential-file-storage.md)执行一次迁移。旧钥匙串条目不会自动删除，也不会被新版作为回退读取。凭证文件是仅当前系统用户可读写的本地明文文件。

安装包：Apple Silicon，macOS 14 或更新版本。附 SHA-256 校验文件。使用本地开发签名，尚未经过 Apple 公证。
