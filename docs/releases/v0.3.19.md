# Arco 0.3.19

## 会议提醒

- 修复飞书原生会议窗口没有可访问按钮时不触发提醒的问题。打开入会预览即可提示，记录仍需点击“开始记录”。
- 缩短提示文案并居中显示，加强“这次不用”按钮的辨识度。
- 提示窗默认居中显示在 Dock 上方，距离可用屏幕底部 16 点；支持拖动标题区域调整位置。

## 验证

- 使用实际飞书窗口复现问题，并通过回归测试验证修复；实际检查提示显示、位置和拖动。
- 完整 Rust、Swift、录音器及本地转写测试通过；安装包通过完整性与严格签名检查。

## 安装

适用于 Apple Silicon，macOS 14 及以上。此预览版本使用 Arco 固定的本地开发签名，尚未经过 Apple 公证。
