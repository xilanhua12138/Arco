# Arco 0.3.3

Arco 0.3.3 removes artificial replay pacing from the Doubao reconnect path so accumulated speech can catch up promptly after a transient outage.

## Fixes

- Drains recovered Doubao audio in source order as quickly as WebSocket backpressure permits, matching LiveKit's streaming STT send-loop behavior instead of delaying packets against the original audio clock.
- Keeps the existing anonymous disk spool, monotonic acknowledgement watermark, and replay of every unconfirmed PCM packet across reconnects.
- Continues to receive provider results while a backlog is draining and preserves the optimized two-pass recognition, speaker separation, heartbeat, speech-progress watchdog, and final-flush behavior.

## Validation

- Adds a red-first regression test proving that three seconds of reconnect backlog is not constrained by the former 2x replay clock.
- Passes all Doubao unit tests, including ordered recovery, acknowledgement-tail replay, heartbeat recovery, response watchdog, and disk-spool reclamation.
- Passes the complete Rust and native macOS validation suites, formatting, and Clippy with warnings denied.
