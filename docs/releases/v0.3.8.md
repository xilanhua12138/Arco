# Arco 0.3.8

Arco 0.3.8 makes the meeting transcript's storage path one click away.

## Features

- The storage row in the meeting-details card now has a copy button that writes the meeting's real transcript path (e.g. `~/Library/Application Support/Arco/transcripts/transcript-….md`) to the pasteboard, with a brief check-mark confirmation. Localized in English and 简体中文.

## Validation

- New TopBar contract assertions: the storage row copies via `NSPasteboard`, the copied value is the real `summary.path`, and the copy affordance stays localized.
- Localization key-count contract updated for the two new keys; all Swift contract suites pass.
