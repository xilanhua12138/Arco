# Arco 0.2.15

Arco 0.2.15 fixes the Ask Arco utility window header layout.

## Fixes

- Vertically centers the Ask Arco title, transcript state, sidebar control, and circular close action across the complete 52-point native toolbar.
- Removes the apparent empty strip below the controls by giving collapsed and expanded header columns an explicit finite height instead of relying on an unresolved SwiftUI infinite-height proposal.
- Keeps the original 3:2 Agent/transcript split, 52-point source density, full-width drag regions, and existing button behavior unchanged.

## Validation

- Added a source-parity regression contract for all three header column states.
- Verified the real 720×560 native Agent panel and confirmed symmetric top/bottom spacing with the workspace beginning immediately below the toolbar divider.
- Passed the complete Rust, SwiftUI, recorder, and local-transcriber test suite.
