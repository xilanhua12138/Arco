# Arco 0.3.7

Arco 0.3.7 keeps the meeting details card visible when it opens above the transcript and agent docks.

## Fixes

- Raises the meeting TopBar above the workspace on the current and review pages. The details card renders inside the TopBar's overlay, and the later workspace was painting over it, so opening a meeting's info card showed it clipped behind the transcript and agent panels.

## Validation

- Adds a TopBar contract test asserting every `TopBarView` call site keeps the raised z-order.
- Passes all Swift contract suites.
