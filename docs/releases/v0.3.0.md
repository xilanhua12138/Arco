# Arco 0.3.0

Arco 0.3.0 refines the native SwiftUI experience with a consistent Apple-style interaction language while preserving the existing product structure and workflows.

## Improvements

- Gives custom controls immediate pointer-down feedback with interruptible, critically damped motion.
- Makes History selection visible and keeps navigation state clear across the main window and Settings.
- Keeps Notes on a stable document surface while reserving Liquid Glass for functional controls.
- Uses spatially anchored, reversible transitions for Settings and transient shell feedback.
- Respects Reduce Motion, Reduce Transparency, and Increased Contrast throughout shared motion and material primitives.
- Improves Settings accessibility names and reports exactly one selected navigation section.

## Validation

- Adds a dedicated Apple-design source contract with 19 assertions.
- Passes all native SwiftUI, source-parity, localization, performance, and window-chrome contracts.
- Passes 227 Rust audio-runtime, core, backend, controller, FFI, and parser-performance tests.
- Builds and signs the native macOS app with the embedded Rust static library and isolated transcription workers.
- Verifies Current, History, Notes, and Settings in the real native application.
