# Arco v0.3.35

“询问 Arco”和“邀请 Arco 入会”现在是并列入口：文字提问和语音参与可以同时使用。

- 主窗口会议标题右侧放置两个同等分量的按钮，文字面板专注于文字交流。
- 录音悬浮条同步增加语音入会入口，调整为 520×56；停止录音仍用独立的红色按钮。
- 未加入时显示邀请，加入中显示进度，入会后显示“Arco 已入会”，失败时提供“重新邀请”。点击已入会入口查看参与状态，离会仍是独立操作。
- 两个入口统一尺寸、图标和悬停反馈；悬浮条仅订阅语音连接阶段，避免音量变化触发整条重绘。

验证：主窗口入口和实际悬浮条组件渲染检查，中文及英文状态检查；367 项界面状态断言、偏好设置、本地化和窗口结构检查通过。保留 v0.3.34 的麦克风选择与语音连接修复。

适用于 Apple Silicon、macOS 14 或更新版本。附 SHA-256 校验文件；使用稳定本地开发签名，尚未经过 Apple 公证。
