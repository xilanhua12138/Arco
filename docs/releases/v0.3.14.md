# Arco 0.3.14

Arco 0.3.14 adds low-overhead meeting awareness for Google Meet and Feishu, and makes capture startup and shutdown immediately responsive.

## Meeting awareness

- Adds a native menu-bar mode that releases the main SwiftUI window and review caches while Arco is idle.
- Uses macOS Accessibility events to recognize active Google Meet and Feishu calls without a repeating polling timer.
- Shows a small, non-activating prompt with direct Start recording and Not this time actions.
- Shows the configured global recording shortcut prominently on the Home screen and keeps the menu-bar action in sync when it changes.
- Pauses automatic meeting prompts after three consecutive dismissals. Prompts can be restored only from Settings.

## Capture reliability

- Returns from capture start immediately while provider setup continues in the background.
- Lets users cancel capture while a cloud provider is still connecting.
- Finalizes capture in the background so the interface remains responsive while provider tail audio is saved.
- Adds bounded Deepgram and ElevenLabs connection timeouts and avoids a duplicate Deepgram finalization round trip.

## Validation

- The complete native, Rust, recorder, localization, settings, overlay, and local-transcription test suites pass.
- Meeting-awareness coverage includes pre-join false positives, active-call detection, once-per-meeting prompts, capture suppression, persisted dismissals, and Settings-only restoration.
- The signed arm64 application and DMG pass strict signature, embedded-runtime, layout, and checksum verification.
