# Arco 0.3.11

Arco 0.3.11 lets you attach reference documents to a meeting as Agent context.

## Features

- Attach a resume, JD, or notes through the composer context menu. Arco extracts the text itself (PDFKit for PDF, UTF-8 for Markdown and plain text) and inlines it into the Agent prompt as guard-tagged quoted material, so the Agent reads the full document without any file-system access. Injection attempts inside meeting audio cannot reach beyond the attached document.
- Attachments persist in the meeting sidecar, appear as removable composer chips, and are disclosed in every answer's context receipts. Each meeting keeps its own attachment set, so one candidate's materials never leak into another interview.
- Limits: up to 8 attachments per meeting, 200,000 characters of extracted text each; duplicate names are rejected.

## Validation

- New integration tests cover the attachment sidecar round trip, field and capacity validation, and prompt inlining with its injection guard and source receipts.
- All Rust core and integration tests pass; all Swift contract suites pass, including localization parity for the new copy.
