# Arco v0.3.24

- 修复从桌面启动时 GPT Live 连接超时：通过用户的登录 Shell 启动，并使用 macOS 原生代理接口为登录、令牌刷新和语音连接选择网络路径。
- 无需在 Arco 中重复配置代理；未配置代理时保持直连，不写死代理地址或修改系统网络设置。
- 加宽会议回顾的转写区域，减少左右空白，并将正文与说话人名称对齐。

此版本的 GPT Live 已验证手动 HTTP CONNECT 代理与直连配置；PAC 自动代理脚本和 SOCKS-only 语音连接暂不支持。

本机验证包含无代理环境变量下的真实模型语音接收，以及已安装程序使用合成静音音频的连接、断开流程。

安装包：Apple Silicon，macOS 14 或更新版本，附 SHA-256 校验文件。使用本地开发签名，尚未经过 Apple 公证。
