# Arco 0.3.18

Arco 0.3.18 refines the meeting workspace, floating companion, and Settings, with a clearer focus on discussing the current meeting.

## Meeting workspace

- Refines typography, spacing, Arco navigation, and transcript presentation while retaining the centered listening action and Home statistics/shortcuts.
- Makes the Ask Arco pane collapsible while preserving the draft, context selection, and native editor when reopened.
- Uses a white reading surface and smaller text in the floating window, with a compact composer and clear recording/saved states.
- Removes the separate Notes page and Save to Notes actions. Text questions and answers remain attached to their meeting automatically. Existing note files are untouched and remain accessible from Data & privacy.

## Settings

- Updates inline connection-test results, provider choices, and Save button state immediately without leaving and reopening Settings.
- Groups settings into General, Listening & recording, Talk with Arco, and Data & privacy. Transcription, title/summary rules, text connections, and voice connections open as details within their parent section.
- Embeds text-provider selection and connection testing in Settings, with a fixed save action that requires a successful test. Results from a previous service selection cannot unlock the current configuration.
- Preserves separate title/summary prompt drafts when navigating back or switching sections. Explicit Cancel discards only that rule's draft.
- Shows actual setup problems in the overview and avoids conflicting installed/version labels.
- Rejects expired GPT Live credentials instead of displaying them as connected. GPT Live remains opt-in Beta; voice and text use separate services.

## Distribution

Apple Silicon, macOS 14+. This preview uses Arco's stable local development signature and is not Apple-notarized.

## Validation

- `make test` passed, covering Rust audio/core/GPT Live, Swift contracts, recorder self-test, and 12 local-transcription checks. The additional Apple-design contract suite passed.
- Release app and mounted DMG passed strict signature and native-boundary checks; DMG integrity and SHA-256 verified.
- Native settings navigation and immediate connection-test progress were checked in the release app. A rendered-control regression covers verification enabling Save and invalidation disabling it.
- The live Codex connection probe timed out on the validation host. These UI checks do not claim a successful live AI, recording, or voice-service session.
