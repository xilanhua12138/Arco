# Arco v0.3.31

历史转录稿支持点击整行跳转。点字词时按对应时间播放，点行内空白时从这一句开始播放。

- 字词悬停显示浅蓝色圆角高亮，保留文字选择与复制。没有字词时间戳的内容使用句子时间。
- 整行悬停与播放状态使用左右留白的圆角背景，分隔线与内容对齐。
- 可播放正文使用原生 TextKit 命中检测与排版，只重绘鼠标所在的文字区域；沿用原生列表的行复用。

验证：字词边界、换行链接、句尾空白命中、录音播放与跳转测试通过；原生 UI 367 项、内容布局 24 项、历史列表 21 项检查通过。一万条记录的首屏仍仅创建 10/11 个原生行视图。验证窗口中点击行内空白成功跳到第五秒；后续截图自动化遇到 ScreenCaptureKit 错误，字词悬停的视觉复核尚未完成。上述检查不包含实际滚动帧率测量。

适用于 Apple Silicon、macOS 14 或更新版本。附 SHA-256 校验文件；使用稳定本地开发签名，尚未经过 Apple 公证。
