# Arco 0.2.0

Arco 0.2.0 is a reliability and native-macOS polish release focused on the complete meeting flow: onboarding, mixed audio capture, live transcription, the recording HUD, and Ask Arco.

## Highlights

- Adds ElevenLabs Scribe v2 Realtime as an online transcription option alongside Deepgram and on-device models.
- Adds independent speech-recognition and speaker-separation model downloads in onboarding and Settings.
- Restores onboarding at the audio-check step after the macOS permission relaunch instead of starting over.
- Checks system audio and microphone one at a time with explicit ready, retry, and restart-required feedback.
- Keeps the live transcript and Ask Arco together in Current while recording, with consistent compact typography and centered waiting states.
- Makes the recording HUD draggable and lets its Ask Arco action toggle the floating Agent open and closed.

## Reliability and performance

- Uses native Liquid Glass without stacking expensive CSS backdrop filters, keeps unfocused overlays out of macOS's protected composition path, and reuses the same hidden native surfaces between meetings. This prevents WindowServer/GPU saturation without replacing the material with a static fallback.
- Cleans up Core Audio process taps, aggregate devices, IO callbacks, microphone taps, and ScreenCaptureKit streams on stop, failure, force quit, or parent exit.
- Prevents a closed transcription pipe from terminating the recorder before native audio resources are released.
- Makes recorder readiness explicit so audio checks and real meetings cannot remain stuck at an ambiguous starting state.
- Dispatches native overlay window mutations to the macOS main thread to prevent the previous `NSWindow` crash.
- Keeps cloud credentials in macOS Keychain with stable app signing and in-process caching to avoid repeated reads during one launch.

This preview is locally signed rather than Apple Developer ID signed. macOS can therefore request one new Keychain approval after installing a newly rebuilt preview, even though subsequent meetings in that exact installed build reuse the approved credential.

## Validation

- Frontend unit and integration tests, Rust unit and integration tests, local-transcriber contract tests, Playwright end-to-end tests, ESLint, Rustfmt, and Clippy.
- Signed DMG, Gatekeeper/codesign verification, installed-app launch, mixed capture, stop cleanup, HUD interaction, and performance sampling on macOS.
