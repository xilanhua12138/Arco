# Arco 0.3.15

Arco 0.3.15 makes menu-bar mode reliable and easier to recognize.

## Fixes

- Prevents a crash when the main window is minimized into menu-bar mode.
- Shows Arco's own monochrome icon in the macOS menu bar without a redundant text label.
- Closes the menu immediately when the user clicks another app or the desktop.
- Removes the redundant idle-status row so the compact menu begins with useful actions.
- Removes the repeated global-shortcut hint from the Home hero; the shortcut remains available in Settings and the Home shortcuts section.

## Validation

- Regression coverage verifies single-owner main-window release, the labelled native status item, and removal of the duplicate Home hint.
- The complete native, Rust, recorder, localization, settings, overlay, and local-transcription test suites pass.
- The signed arm64 application and DMG pass strict signature, embedded-runtime, layout, and checksum verification.
