# Arco 0.2.19

Arco 0.2.19 restores Doubao speaker separation and makes the optimized two-pass stream recover reliably when the provider connection becomes half-open or stops returning results.

## Fixes

- Reads Doubao's actual zero-based `utterance.additions.speaker_id`, so remote and in-room speakers no longer collapse into the same speaker.
- Keeps compatibility with the legacy one-based `utterance.additions.speaker` field.
- Sends WebSocket heartbeats and reconnects when the provider stops replying.
- Detects active speech with no recognition progress and reconnects instead of leaving the session silently stalled.
- Replays unconfirmed PCM after reconnecting so speech around an interrupted connection is not discarded.

## Validation

- Adds red-first regression coverage for the production `speaker_id` payload, legacy speaker payloads, missing heartbeats, and silent half-open streams.
- Passes all 216 Rust tests, formatting, and Clippy with warnings denied.
- Passes a real Doubao optimized two-pass provider test with two synthetic speakers, yielding both `In room 1` and `In room 2` segments across the heartbeat interval.
