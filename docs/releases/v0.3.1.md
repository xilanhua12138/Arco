# Arco 0.3.1

Arco 0.3.1 makes capture start reliably on the first click, restores live first-pass Doubao captions, and lightens the native sidebar material without changing the product structure.

## Fixes

- Waits for the capture runtime to finish initializing before starting a meeting, so the first **Start listening** click is no longer lost.
- Shows Doubao optimized two-pass first-pass text while people are still speaking instead of waiting for the second-pass final boundary.
- Keeps tentative Doubao text display-only; History and the final Markdown transcript still contain only finalized second-pass lines.
- Polls the active meeting at a caption-friendly cadence while preserving the existing reconnect, heartbeat, PCM replay, and speaker-separation protections.
- Uses a lighter native sidebar material and keeps the current selection readable without the previous heavy gray cast.

## Validation

- Adds red-first regression coverage for capture initialization and live tentative Doubao captions.
- Passes all 229 Rust audio-runtime, core, backend, controller, FFI, and parser-performance tests, plus formatting and Clippy with warnings denied.
- Passes all 12 native SwiftUI contract executables with 568 assertions.
- Passes a real Doubao optimized two-pass provider test: first-pass text appears during speech, then resolves to one clean finalized transcript line.
- Builds and signs the native macOS application with its embedded Rust static library and isolated transcription workers.
