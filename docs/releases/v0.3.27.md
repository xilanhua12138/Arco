# Arco v0.3.27

历史记录现在可以直接播放会议录音，并与转录稿互相定位。

- 点击词语或句子时间，从对应位置开始播放；播放时高亮当前内容并跟随滚动。手动浏览转录稿会暂停跟随，可一键恢复。
- 新增紧凑的浅灰播放器，采用 Mizzen Responses 的布局，显示真实录音波形、时间和 1× / 1.5× / 2× 倍速。拖动波形可定位对应转录稿。
- Deepgram、豆包、ElevenLabs 和本地 Whisper / Nemotron 适配器保留模型返回的字词或 token 时间，并处理分段、重连与续录偏移。Nemotron 的 token 时间是近似帧位置。
- 兼容旧记录的句级时间戳；过去未保存的词级时间不会自动补齐。没有录音的会议会显示说明，缺失录音分片会被跳过。
- 切换会议或关闭面板时停止播放，支持查找历史归档目录中的录音。

通过 Rust 时间戳与归档测试、AVFoundation 播放联动测试、原生应用 contract tests 及安装包校验。真实音频验证了 Whisper Tiny 与 Nemotron；其他 Whisper 大小共用适配路径，云端供应商本次验证覆盖解析与构建，未逐家进行真实识别测试。

适用于 Apple Silicon、macOS 14 或更新版本。附 SHA-256 校验文件；使用稳定本地开发签名，尚未经过 Apple 公证。
