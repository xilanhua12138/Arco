# Arco v0.3.33

现在可以在「设置 → 聆听与记录」选择麦克风。修复系统默认输入为 BlackHole 时，内置麦克风可用却无法开始录音的问题。

- 麦克风选择支持自动选择、内置麦克风及外接设备，使用与设置页一致的自定义下拉控件。
- 保存所选设备，显示下次录音使用的麦克风。设备断开后提示回退；重新连接后，下次录音恢复原选择。录音期间锁定选择。
- 自动选择排除虚拟设备、聚合设备和只有输出的设备；默认输入不可用时优先寻找内置麦克风。
- 麦克风初始化失败时展示录音组件的原始原因，避免下游转录进程的正常退出掩盖错误。

验证：默认输入为 BlackHole 时完成内置麦克风的短暂本地采集，收到就绪信号并正常退出。设备保存、断开重连、自动选择、保存失败、设置控件和本地化检查通过；22 项采集集成测试、20 项采集单元测试及录音组件自测通过。

适用于 Apple Silicon、macOS 14 或更新版本。附 SHA-256 校验文件；使用稳定本地开发签名，尚未经过 Apple 公证。
