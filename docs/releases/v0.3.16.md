# Arco 0.3.16

Arco 0.3.16 introduces opt-in GPT Live voice questions as a Beta and improves live-audio reliability.

## GPT Live Beta

- Adds a dedicated **Settings → GPT Live** page with a Beta label, an off-by-default toggle, and ChatGPT OAuth connect, reconnect, and disconnect controls.
- Adds a meeting-only voice button beside Ask Arco. Audio is sent only after the user clicks the button, and the session ends when the user disconnects, stops the meeting, disables the Beta, or quits Arco.
- Runs WebRTC, Opus, sideband control, OAuth refresh, and audio playback in a separately signed Rust worker built from maintained libraries rather than a custom WebRTC implementation.
- Delegates questions about meeting progress, decisions, and open items to the current transcript-aware Codex or Claude Agent before GPT Live speaks the result.
- Keeps GPT Live failures isolated from recording and transcription. “Hey Arco” wake-word activation is not included in this release.

## Audio and transcript fixes

- Adds packet reordering, bounded prebuffering, loss concealment, and playback buffering to reduce choppy GPT Live speech.
- Prevents the GPT Live worker from hearing its own playback while keeping that answer in the normal meeting recording as a participant contribution.
- Deduplicates the same acoustic answer captured through both system audio and microphone lanes, and rejects repeated provider final segments without removing genuine later repetition.
- Disconnects GPT Live and cancels outstanding delegated Agent work when the meeting stops.

## Compatibility notice

GPT Live is experimental, off by default, and uses a ChatGPT backend interface that OpenAI does not document as a stable public API. Availability may differ by account and may change without notice. Arco does not silently switch to a separately billed OpenAI API when this Beta is unavailable.

The downloadable macOS preview keeps Arco's local development signature and is not Apple-notarized. First launch may require Control-clicking `Arco.app` and choosing **Open**.

## Validation

- Rust unit, integration, OAuth, WebRTC, media, sideband, playback, and transcript-deduplication tests pass.
- Swift UI, settings, preferences, localization, lifecycle, overlay, and source-parity contract tests pass.
- The signed Apple Silicon application and DMG pass embedded-worker, code-signature, layout, mount, launch, and checksum checks.
