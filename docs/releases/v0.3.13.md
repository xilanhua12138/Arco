# Arco 0.3.13

Arco 0.3.13 fixes Chinese input-method composition in Ask Arco and removes unnecessary Liquid Glass from provider setup.

## Fixes

- Preserves marked input-method text while live transcript updates refresh the Agent view, so Chinese pinyin composition and candidate selection are no longer cleared before commit.
- Hides the Agent composer placeholder as soon as the editor receives focus, preventing placeholder copy from overlapping input-method pre-edit text.
- Replaces the provider setup sheet's nested Liquid Glass layers with stable opaque surfaces, explicit selected fills, restrained borders, and lightweight press feedback.

## Validation

- Regression coverage verifies marked-text synchronization, placeholder visibility, and the absence of decorative Liquid Glass in provider setup.
- Swift content, setup, native UI, Apple design, and overlay contract suites pass, and the complete native application builds successfully.
