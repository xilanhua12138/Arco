# Arco 0.2.16

Arco 0.2.16 makes live Agent work inspectable, hardens Doubao streaming transcription, and polishes the native Ask Arco composer.

## Improvements

- Shows live and completed Agent tool activity with elapsed time, status, input, and output disclosures while preserving the meeting answer as the primary reading surface.
- Moves Doubao recognition to the optimized asynchronous two-pass endpoint with explicit audio sequencing, a separate final flush packet, and provider-duration-based acknowledgement.
- Keeps audio sending and recognition results moving concurrently, including during reconnect replay, instead of stalling live capture behind sparse provider responses.
- Handles leading digital silence locally, preserves cumulative definite utterances exactly once, and accepts optimized results that omit or stringify timing metadata.

## Fixes

- Aligns the Ask Arco caret and placeholder to the same native TextKit inset.
- Gives the floating Agent workspace one stable high-opacity reading substrate when the window is not focused.
- Removes the detached white composer rectangle and keeps the disabled send arrow legible without fading the whole button.

## Validation

- Covers normal, boundary, reconnect, silence, sparse-result, cumulative-result, timeout, and finalization paths in the Rust transcription tests.
- Adds native source-parity regressions for the composer inset, inactive workspace substrate, inherited composer background, and disabled send treatment.
- Builds and verifies the signed native app, bundled recorder and transcription workers, and drag-to-Applications DMG.
