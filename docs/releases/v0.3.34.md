# Arco v0.3.34

现在可以在「设置 → 聆听与记录」选择麦克风。录音和语音助手都会使用所选设备；系统默认输入为 BlackHole 时，也能找到可用的内置麦克风。

- 使用设置页的自定义下拉控件选择自动、内置或外接麦克风，并保存选择。
- 所选设备断开时显示回退设备；重新连接后，下次录音恢复原选择。录音期间锁定选择。
- 修复语音助手连接时仍要求系统默认输入为实体麦克风的问题。会议音频路由使用所选实体麦克风，退出时恢复此前的系统输入。
- 麦克风初始化失败时保留原始原因，并显示中文处理提示；语音浮窗中的错误说明支持换行。

验证：在系统默认输入为 BlackHole 的环境下，录音器完成内置麦克风采集；语音组件读取保存的设备、建立本地会议音频路由并正常退出，退出前后系统音频设备设置一致。设备配置、设置控件、本地化、录音启动和语音路由测试通过。本次验证未新建云端语音会话。

适用于 Apple Silicon、macOS 14 或更新版本。附 SHA-256 校验文件；使用稳定本地开发签名，尚未经过 Apple 公证。
