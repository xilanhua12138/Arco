# Arco v0.3.32

修正转录稿字词悬停与点击的对应关系，并统一历史会议列表的圆角行背景。

- 悬停和点击共用字词范围与时间映射。系统合并相邻链接时，仍按点击的词取时间。
- 只有真实保存了逐词时间戳的文字显示词级悬停。仅有句子时间戳的旧录音显示“按句跳转”，点击从本句开头播放。
- 文字选区、播放高亮和悬停高亮按优先级显示，避免同一区域重复着色。
- 历史会议整行可点，悬停和选中背景增加左右留白及圆角；取消行悬停的渐变动画。

验证：原生字词命中与错误句首链接回归、换行、空白命中、播放高亮转换、播放跳转、历史列表复用、原生 UI、设计与本地化检查通过。截图自动化仍遇到 ScreenCaptureKit 错误，尚未完成悬停视觉复核；本次未测量实际滚动帧率。

旧录音若未保存逐词时间，仍需音频对齐才能支持精确到词；此版本保留其原始转录数据。

适用于 Apple Silicon、macOS 14 或更新版本。附 SHA-256 校验文件；使用稳定本地开发签名，尚未经过 Apple 公证。
