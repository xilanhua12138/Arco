# Settings layout refinement

Use the supplied Typeless settings screenshot as the visual reference: a light gray navigation column, a white content surface, quiet icon-led group headings with thin dividers, and generous spacing between groups. Keep the four existing Arco destinations and all settings actions.

The sheet grows to fit the window (up to 1040 × 760 points). Setting labels use 14-point system type; helper text remains secondary. Shared controls use a 236-point track and 40-point menu height, stacking when the available width is insufficient. Row separators are replaced by section separators. Menu borders belong to the control container so the native macOS menu style cannot discard them.

Language and shortcut help are visible. Detail destinations retain their parent selection and return action. The general page no longer overrides every child accessibility label with a shared container label.
