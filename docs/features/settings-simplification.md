# 设置页精简

设置保留四个分类：通用、聆听与记录、与 Arco 对话、数据与隐私。每行左侧说明设置项，右侧放当前值或操作。标题明确的地方不再重复解释。

| 页面 | 常驻内容 | 按需展开的内容 |
| --- | --- | --- |
| 通用 | 界面语言、聆听快捷键、会议提示、软件更新 | 权限缺失或提示暂停时，直接显示恢复操作 |
| 聆听与记录 | 会议类型、语音识别入口、标题与摘要入口 | 只显示所选会议类型的音频来源说明 |
| 语音识别 | 识别服务、凭证状态、说话人分离服务 | 选择本地后显示模型；移除凭证放入账号菜单 |
| 标题与摘要 | 两项规则与当前状态 | 自定义提示词和默认提示词在规则编辑页显示 |
| 与 Arco 对话 | 文字对话、语音对话及当前状态 | 连接配置各自进入详情页 |
| 文字对话 | 主要服务、备用服务、连接测试、保存 | CLI 版本与重新检测放入安装详情 |
| 语音对话 | 启用开关、ChatGPT 登录状态 | 已连接时，重新登录与断开放入账号菜单 |
| 数据与隐私 | 录音开关、已用容量、容量上限、打开文件夹 | 路径、修改位置、恢复默认位于存储菜单；格式、旧笔记及隐私说明可展开 |

存满自动清理旧录音、保留文字记录的说明始终可见。切换存储目录只影响之后的会议，不迁移或删除已有文件。录音期间仍禁止修改来源、识别方式和存储设置。凭证错误、下载进度与连接失败仍直接显示。

本次改动只调整设置的展示与控件组织，不改变存储格式、容量策略、服务配置或会议数据。设置页继续使用统一字体接口，字体选择由独立的字体调整处理。

验证包括设置行为测试、国际化完整性、已挂载 SwiftUI 的连接按钮更新、真实 Rust 存储接口，以及独立预览应用中的菜单、开关、锁定状态和规则保存。预览应用使用单独的测试数据目录，不读取或修改正在使用的 Arco 配置。
