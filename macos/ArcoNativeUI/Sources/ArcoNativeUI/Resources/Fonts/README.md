# Syne wordmark font

Only the standalone Arco brand wordmark uses Syne Bold (weight 700). Other UI text retains the macOS system font.

Unmodified variable font from Google Fonts:
https://github.com/google/fonts/blob/main/ofl/syne/Syne%5Bwght%5D.ttf
